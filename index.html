Image Sync with Subtitle

One subtitle block = one clip duration

Independent of CapCut's own subtitles. Paste SRT-format text (with timestamps) or upload a .srt file — each block retimes the matching image/clip. Your CapCut subtitle track is not touched.

Sync to Audio Cuts

One audio cut = one clip duration

Retimes each image/video clip on the primary visual track to match the cuts on the project's audio track — no SRT or upload needed. Split your audio into segments in CapCut (one segment per clip you want), then click Sync to Audio Cuts.

  • Reads timing straight from the audio track's segments (in order).
  • Photos take any length; real footage is capped at its source duration.
  • Extra clips beyond the audio cuts are laid out in sequence.
  • A full backup is created first, and CapCut must be closed.

Motion

Ken Burns animation for every clip

Adds a Ken Burns keyframe animation (Zoom, Pan, Ken Burns, or Cycle) to every image and video clip on the project's video tracks. Existing scale/position keyframes are replaced; other keyframes are kept.

Transitions

Randomly distribute your transitions

Detects the first 5 transitions already used in the project and reassigns them randomly to every clip, keeping each transition's original duration and settings.

Export

Export CapCut's subtitle track as .srt

Reads CapCut's subtitle (text) track with timings and downloads a timestamped .srt file. This is read-only — your project is not modified.

Backups

Safety copies of the whole project

Every editing action already creates an automatic backup first. Use Backup Project for a manual snapshot, or Restore Backup to roll back to the latest saved copy (a safety backup of the current state is taken before restoring).

Tools

CapCut helpers

Kill CapCut force-closes CapCut so it releases the project from memory — external edits only show up after a fresh reopen. Clear Cache deletes stale .tmp/.bak sidecar files for the selected project (the real draft is never touched). CapCut must be closed for cache clearing.
